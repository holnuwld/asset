- **GitHub Pages 배포 주소**: [https://holnuwld.github.io/asset/](https://holnuwld.github.io/asset/)
- **포트폴리오 기준일**: 2026년 11월 3일 (`금융자산_261103`)
- **총 평가 자산**: 약 **10억 6,000만원** (원금 8억 4,056만원, 평가손익 +2억 1,949만원, 수익률 +26.11%)

## 📊 주요 기능

1. **다차원 자산배분 100% 단일 누적 막대 그래프**
   - 위험/안전자산 (Risk-on 65% : Risk-off 35%)
   - 통화별 비중 (KRW 72% : USD 23% : JPY 5%)
   - 주식 내 국가별 비중 (한국 75% : 미국 21% : 일본 4%)
   - 만기/유동성 비중 (유동자산 97% : 고정예금 3%)
   - 9개 실사용 계좌 비중 및 **5/25 리밸런싱 허용오차 밴드**
   - 각 자산군 막대 클릭 시 하단에 **인터랙티브 자산별 추이 그래프** 연동

2. **외부 원금 추가납입 및 MWRR (수정 디츠법) 수익률 반영**
   - 외부 자금 입출금 발생 시 단순 수익률 왜곡 방지
   - 일자별 가중평잔 적용 평잔수익률(MWRR) 및 원금 곡선 동시 표시

3. **월간 / 연간 실현손익 & 기간별 매매 조회**
   - 월별 확정 실현손익 및 연간 누적 손익 트래킹
   - 해외주식 양도소득세 250만원 기본공제 잔여 한도 실시간 계산
   - 기간별(1주/1개월/3개월/1년/전체), 계좌별, 거래유형별(매수/매도/만기/입금) 필터 테이블

4. **상단 거시/시장 지표 바**
   - 실시간 환율 (USD/KRW, JPY/KRW, EUR, CNY)
   - 주요국 10년/30년 국채금리 변동 (bp 단위)
   - 주요 지수 (나스닥, 코스피, 코스닥, 니케이)
   - KRX 금현물 시세 및 비트코인(달러 시세, 업비트 원화 시세, **김치프리미엄 % 자동 계산**)

5. **최초 자산 CSV 업로드 & 드래그 앤 드롭 일괄 등록**
   - CSV 파일 직접 선택 및 드래그 앤 드롭 지원
   - 실시간 파싱 미리보기 테이블 & 유효성 검증 배지
   - `샘플 양식 다운로드` 지원

6. **텔레그램 문자 파싱 & 롤백 시뮬레이터**
   - 정규식 기반 증권사 체결 문자 파싱 (삼성, 키움, 나무, KB, 새마을 등)
   - 즉시 체결 회신 및 오인식 시 `/취소` 롤백 지원 (공매도/수량부족 사전 방지 원장 재생)

## 🚀 로컬 실행 방법

별도의 서버 없이 브라우저에서 `index.html` 파일을 더블 클릭하여 바로 오프라인/스탠드얼론으로 사용할 수 있으며, 로컬 SQLite DB 백엔드와 연동하려면 아래 명령을 실행합니다:

```cmd
.\run.bat
```

서버 실행 후 브라우저에서 `http://localhost:8000`으로 접속됩니다.
